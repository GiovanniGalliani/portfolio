# Giovanni Galliani — Portfolio

A responsive, accessible, single-page professional portfolio built with plain HTML, CSS and JavaScript. No build tools or dependencies are required.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy

Upload the contents of this folder to any static hosting provider. For GitHub Pages, push the files to a repository and enable Pages from the repository's Settings. For Netlify, drag and drop the folder in the Netlify dashboard or connect the repository. No build command is needed; the publish directory is the project root.

## Personalize before publishing

- Add a verified custom domain and canonical URL if available.
- Replace the decorative hero illustration with a professional portrait if desired, including descriptive alt text.
- Add case studies only after confirming the project scope, outcomes and any client confidentiality restrictions.
- The CV PDF is not bundled; add a public CV download only after deciding which version to publish.

The site uses Google Fonts when online and falls back to system fonts if they are unavailable.
